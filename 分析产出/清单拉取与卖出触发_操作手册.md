# 打新底仓 · 清单拉取与卖出触发（操作手册）

> 一句话：**拉清单看日历，卖出看资格。** 前者是固定动作，后者只在规则被破坏时发生。
> 股价跌了多少，不在这套逻辑里。

---

## 一、什么时候重新拉清单

| 锚点 | 时间 | 命令 | 做什么 |
|---|---|---|---|
| **年度全量** | 4/30 年报截止后、5 月第一个交易周 | `python annual_review.py --refresh` | 全量：入选资格 + 卖出触发 + 观察池 |
| **半年报轻量** | 8/31 半年报截止后、9 月第一个交易周 | `python annual_review.py --half --refresh` | 只看：卖出触发线（尤其粤高速A 净利、银行核心一级） |
| 其他时间 | — | 不拉 | 季度波动不是卖出理由 |

**为什么半年报只做轻量**：半年报数据完整度不足以支撑全量判定（现金流量表是累计值、部分标的未做中期分红），强行全量会得出偏差结论。轻量的目的是捕捉"最紧急的恶化信号"，不是重新筛一遍。

**为什么不每季度拉**：底仓是低波资产，季度层面的数据波动大多会自我修复。频繁复核的代价不是时间，而是**你会开始给噪音找理由**——看到一次支付率跳到 85%，很容易顺手就调了仓。

脚本对不在窗口内的运行不会报错，但报告标题会标「非复核窗口（跟踪）」，结论不宜直接执行。

## 二、两层判定，绝不能合并

复核脚本把每只标的判两遍，回答两个不同的问题：

| 层级 | 回答的问题 | 不通过的后果 |
|---|---|---|
| **入选资格**（entry） | 当初为什么选它？理由还在不在？ | 只记录，不构成动作 |
| **卖出触发**（exit） | 底仓资格 / 分红纪律是否被破坏？ | 触发即动仓 |

典型的分歧场景：

- 洪城环境支付率从 50% 升到 82% → 入选资格 FAIL（要求单年 <80%），但**卖出线是连续两年 >80%**，第一年不动仓。
- 沪农商核心一级从 9.6% 掉到 9.3% → 入选资格 FAIL（要求 ≥9.5%），但**卖出线是 9.0%**，只降权不清仓。
- 唐山港波动率从 22% 升到 24.5% → 仍在 25% 红线内，不动。

**刻意设置的两条缓冲带**：

| 指标 | 入选线 | 卖出线 | 缓冲带的作用 |
|---|---|---|---|
| 银行核心一级 | 9.5% | **9.0%** | 容纳 0.5pct 的经营波动 |
| 公用/交运支付率 | 单年 <80% | **连续两年 >80%** | 容纳单年项目结算节奏 |

如果两层用同一个数字，一次正常波动就会触发清仓。

## 三、卖出触发线（黑天鹅 + 四类标的）

### 第零类：所有标的 —— 黑天鹅一票否决（定性，不看财务数据）

上面所有线都是慢变量，恶化要 1–2 个报告期才看得见。合规与安全事故是快变量——财务数据还没反映，股价已经崩了。

| 触发事件 | 动作 |
|---|---|
| 实控人 / 董事长 / 财务总监被立案调查或采取强制措施 | **无条件清仓** |
| 审计报告被出具非标意见（保留 / 无法表示 / 否定） | **无条件清仓** |
| 重大安全、环保事故导致主营业务停摆 | **无条件清仓** |
| 财务造假被证监会立案，或被实施退市风险警示 | **无条件清仓** |

**操作**：在 `黑天鹅登记簿.csv` 加一行（`symbol, name, date, type, detail, status, clear_date`），下次跑 `annual_review.py` 会在报告最顶部报警并把该标的判为【移出】。

**三条必须守住的规矩**：

1. **未登记 ≠ 已确认无风险。** 脚本抓不到立案调查和审计意见，这套机制是"登记即触发"，不是自动巡检。
2. **状态留空视为有效。** 宁可因为漏填状态多报一次警，也不要让真正的风险被静默忽略。
3. **解除要写依据。** 在 `detail` 补"XX 事项已结案/撤销，文号 XXX"，不能只把 `status` 改成"已解除"。

**配套季度人工巡检（5 分钟）**：审计意见类型、监管处罚/问询、实控人与财务总监变动、安全环保事故、重大诉讼。**登记簿空着不代表安全，只代表还没人填。**

### 第零类之二：深市 —— 治理底线一票否决（结构化，自动判定）

与黑天鹅相反，这条**不需要人工登记**：实控人字段来自交易所披露，脚本直接判。

| 实控人性质 | 结论 | 动作 |
|---|---|---|
| 中央国有企业 / 地方国有企业 / 无实际控制人 | 通过 | 正常持有 |
| 个人或家族（自然人） | **否决** | 不得入选；已持仓 → **清仓换仓** |
| 民营（非国资法人） | **否决** | 同上 |
| 外资企业 | **否决** | 同上 |
| 字段缺失 / 抓取失败 | **缺失** | 不通过，进异常表（缺数据 ≠ 达标） |

**当前状态：8 只全部通过，0 项待处理。** 上一轮触发的双汇发展（实控人「兴泰集团有限公司」——法人、非国资）已于 **2026-10-19 清仓**，由粤高速A 替补。当时它的支付率 98.6%、OCF/分红 1.28 都还达标，但治理底线是**身份属性，不随财报改善而消失**，所以不能被好财务抵消——「等 2026 年报再看」没有意义，年报改得了数字，改不了股权结构。

**怎么跑**：`python ownership.py --refresh` 重抓并重判；`annual_review.py` 会读缓存，缺失的现场补抓。持仓与权重以 `打新底仓_最终8只组合_v2.csv` 为机器真源、`打新底仓_最终配置.md` 为人读版本，两者由同一次运行生成，改了一只必然同时改另一份。

**为什么只对深市硬约束**：它是深市子池的第 ④ 条底线。沪市 5 只持仓经核查全部为地方国企或无实际控制人，不存在冲突；要升级为全池硬门，改 `annual_review.py` 的 `GOV_MARKETS = ('沪','深')` 一行即可。

**这条线的失效方式与黑天鹅相反**：黑天鹅怕"忘填"，治理底线怕"**误杀**"——白名单覆盖不到的国资平台会被判成"非国资法人"而否决。误杀可修正（补 `国资主体白名单.csv`，每条写依据后重跑），误放不可逆。所以默认从严。

### 第一类：银行（渝农商、平安银行）—— 看"分红资格"是否被破坏

卖出的核心不是利润下滑，而是**资本不足以支撑继续分红**。

| 触发线 | 级别 | 动作 |
|---|---|---|
| 核心一级 < **9.0%** | 移出 | 资本受限，分红空间被监管压缩，底仓的股息对冲功能失效 → 清仓 |
| 核心一级 9.0%–9.5% | 降权 | 该市场内权重减半，跟踪 |
| 拨备 < 180% **且** 不良率环比上升 | 移出 | 抵补能力与资产质量同时恶化 → 清仓 |
| 拨备 < 180%，不良未上行 | 降权 | 单点跌破，降权观察 |
| 不良率环比上升且 > 1.5% | 降权 | 单看不良不构成清仓 |

> **拨备与不良是"与"关系，不是"或"**。单独拨备跌破 180% 只说明抵补变薄，可能是主动加大核销；只有同时看到不良上行，才是资产质量实质恶化。

### 第二类：公用事业 / 交运（洪城、唐山港、青岛港）—— 看"分红纪律"

| 触发线 | 级别 | 动作 |
|---|---|---|
| 支付率**连续两年** > 80% | 移出 | 用留存利润甚至负债分红，不可持续 |
| OCF/分红**连续两年** < 1 | 移出 | 分红没有真金白银覆盖 |

单年超限不触发。连续两年才算——一年的高支付率可能只是项目结算节奏或一次性收益。

### 第三类：深市三只（格力、平安银行、兴蓉）—— 低波类债，看分红纪律与波动

| 标的 | 触发线 | 级别 | 动作 |
|---|---|---|---|
| **格力电器** | 支付率连续两年 > 75% | 降权 | 深市内权重回调 |
| **格力电器 / 兴蓉环境** | OCF/分红连续两年 < 1 | 移出 | 分红没有真金白银覆盖 → 深市替补递补 |
| **兴蓉环境** | 支付率连续两年 > 80% | 移出/降权 | 用留存或负债分红不可持续 |
| **平安银行** | 核心一级 < 9.0% / 不良环比升且>1.5% / 拨备<180%且不良升 | 移出或降权 | 同"第一类银行"口径 |
| 三只共用 | 年化波动率（252 日）> 25% | 移出/降权 | 低波是这类标的入选的核心理由 |

> 深市持仓全为年化波动 <25% 的低波类债标的（格力 16.7% / 平安 16.2% / 兴蓉 19.3%）。触发卖出时由深市替补席（涪陵榨菜、粤高速A、现代投资，按顺位）递补。

### 第四类：所有标的共用 —— 底仓资格红线

| 触发线 | 级别 | 动作 |
|---|---|---|
| 年化波动率（252 日） > **25%** | 移出 | 降权至 15% 以下或移出 |

**这条与分红完全无关，且不因银行身份豁免。** 选它是为了打新底仓的市值稳定器作用，不是为了收股息。波动率超标意味着这个功能已经失效——分红再好也得让位。

## 五、触发之后怎么处理

脚本会标出触发项，但**"要不要卖"不是脚本能决定的**。三步：

1. **看是哪一项触发**。银行资本、分红纪律、波动红线，三类问题的性质完全不同。
2. **判断是单年波动还是趋势**。连续两年是趋势，单年更可能是节奏。
3. **再决定动作**：按预案降权 / 移出 / 接受并记录理由。

**两个例外，不需要这三步：**

- **黑天鹅**：不判断、不权衡、不当期观察，直接清仓。它是快变量，等你把三步走完，价格已经反映完了。
- **替补递补**：移出深市某只后，按 `深市替补席_2026-11-04.csv` 的顺序取第一只**资格仍有效**的，权重沿用被替标的（超 25% 上限则压到 25%）。**触发时不重新筛选、不重新讨论顺序**——顺序是平静时定的。

典型判断：

- 粤高速A 支付率 100.5% → 说明在用存量现金维持 70% 承诺，按预案减半（单年）；
- 粤高速A 支付率连续两年 101% → 不是"再减半"，而是该考虑清仓（趋势）；
- 沪农商核心一级 9.2% → 降权，不是清仓（仍在 9.0% 上方）；
- 洪城波动 25.5% 一个月 → 先看是否全市场波动抬升，可能只是系统性行情，此时"移出"会卖在低点。

**替补席失效怎么办**：若第一名资格已失效（脚本标 FAIL），跳到第二名；三只全失效，才重新跑深市筛选。此时是真正的"临时决策"，必须按第四节的三条底线重筛，不能凭印象挑一只。

## 六、六个常见误操作

1. **把入选资格偏离当成卖出信号。** 支付率从 50% 到 82%，入选资格 FAIL，但没到"连续两年"的卖出线。看到 FAIL 就调仓，等于把缓冲带取消了。
2. **把黑天鹅交给财务指标判断。** "等年报看支付率有没有恶化"——审计非标和立案调查不会等年报，等你看到数据时已经跌完了。
3. **把"该期宣告支付率"当成年度支付率。** 半年报模式下有些标的只显示半年的宣告额（一年分两次派息的公司尤其明显）；判断阈值只能看"最近完整财年"那一列。
4. **把缺数据当成达标。** 银行指标抓不到时脚本标 SKIP 并计入「数据完整性」，不静默 PASS。缺数据≠条件满足。
5. **用"补分红"心态加仓。** 支付率高的标的往往是因为股价跌了才显得股息率高，不是公司多分了钱。
6. **季度频繁拉清单。** 见第一节。

## 八、脚本的边界

`annual_review.py` 能判断规则是否被触发，不能判断：

- 这次触发是趋势还是噪声（它只提供连续/不连续的事实）；
- 估值是否已经反映了坏消息；
- 有没有更好的替代标的；
- 宏观或行业环境是否让阈值本身该调整；
- **是否发生了黑天鹅**——它不读新闻、不读公告，只认登记簿里有没有人填了那一行。

**判定通过不等于决策正确。** 规则的价值是让"为什么持有"和"什么情况下放弃"在平静时就想清楚，执行时不必临时找理由。**黑天鹅那条线尤其如此：它的可靠性完全取决于你有没有按时巡检。**

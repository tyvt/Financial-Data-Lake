---

## 一、现象

`daily_bars_adj.qfq_close` 与 `daily_bars_adj.close` **数值完全相等**，前复权实际上从未生效。

具体表现：

1. 除权日当天，`qfq_close` 未按分红/送转比例回溯调整，价格缺口被原样保留；
2. `pre_close` 为除权后的参考价，导致 `close / pre_close - 1` 把除权当成真实下跌计入收益率；
3. `adj_is_exact` 标志为 `false` 时不报错、不告警，下游无法感知数据不可信；
4. `hfq_close` 同样存在该问题（后复权亦未生效）。

**该缺陷不会抛异常，只会让所有依赖历史收益率的计算结果系统性偏低（价格层面）/偏高（波动率层面）。**

---

## 二、复现步骤

### 2.1 直接观察

```sql
SELECT trade_date, close, pre_close, adj_close, qfq_close, hfq_close, adj_is_exact
FROM daily_bars_adj
WHERE symbol = '601288.SH'
  AND trade_date BETWEEN DATE '2026-05-11' AND DATE '2026-05-15'
ORDER BY trade_date;
```

实际输出（农业银行，2026-05-13 除权，10 派 1.30 元）：

| trade_date | close | pre_close | qfq_close | 表观涨跌 | adj_is_exact |
|---|---|---|---|---|---|
| 2026-05-12 | 6.78 | 6.79 | **6.78** | −0.15% | false |
| 2026-05-13 | 6.66 | 6.78 | **6.66** | **−1.77%** | false |
| 2026-05-14 | 6.65 | 6.66 | **6.65** | −0.15% | false |

`qfq_close` 逐日等于 `close`，无任何复权痕迹。

### 2.2 缺口未修正的量化验证

农业银行每股派息 0.13 元，除权日前收盘 6.78 元：

```
理论除权参考价 = 6.78 − 0.13 = 6.65
理论跌幅        = 0.13 / 6.78 = 1.918%
实际表观跌幅    = (6.66 − 6.78) / 6.78 = −1.77%
```

表观跌幅 −1.77% 与分红率 1.918% 高度吻合，证明该日"下跌"完全由除权造成，而复权序列未做任何调整。同类案例：601288.SH 2025-07-17、2025-12-15、601825.SH 2026-06-18，表现一致。

### 2.3 全市场验证

对 2025-10-01 以来全市场截面统计（本轮筛选时点实测）：

| 指标 | 数值 | 口径 |
|---|---|---|
| `qfq_close = close` 的行占比 | **≈100%** | 2026-10-15 单日截面 |
| `adj_is_exact = false` 占比 | **60.9%** | 2026-10-15 单日截面 |
| 受影响范围 | 全市场（沪深主板、创业板、科创板） | — |

> **⚠ 口径边界（请勿误读为全历史均值）**
>
> 本轮复核时，`meta/revisions/data/adj_factors/...` 分区被运行环境安全策略拦截（`IO Error: ... 拒绝访问`），**无法读取 revisions 分区做历史回溯全量扫描**。因此 60.9% 是 **2026-10-15 单日截面快照**，不是全历史平均值。
>
> **不排除该比例在除权密集期（A 股分红高峰集中在 5–7 月）更高**——除权事件集中的交易日，因子缺失的标的占比会上行。维护方修复时应以**全量重算结果**作为基准，不要以 60.9% 作为验收基线；若全量结果显著高于 60.9%，说明缺失程度比本节估计的更严重。

## 三、影响评估

### 3.1 受损的下游计算

| 计算类型 | 影响方向 | 量级 |
|---|---|---|
| 年化波动率（日收益率标准差） | **系统性高估** | 实测高估 0.0–1.0 pct |
| 区间涨跌幅（含分红再投资） | 系统性低估 | 等于累计分红率 |
| 最大回撤 | 系统性高估 | 视分红频率 |
| 夏普比率 / 信息比率 | 分子分母同时失真 | 不可预测 |
| 动量/反转因子 | 除权日产生假信号 | 单日 −1%~−7% 噪声 |
| 均线、突破类技术指标 | 除权日产生假跌破 | 同上 |

### 3.2 对本次筛选的具体影响

以核心池 8 只为例，用未修正的 `qfq_close` 计算 252 日年化波动率，与用 `corporate_actions` 重建后的正确值对比：

| 标的 | 原 `qfq_close` | 重建复权 | 虚增 |
|---|---|---|---|
| 唐山港 | 23.17% | 22.18% | **+0.99 pct** |
| 羚锐制药 | 24.05% | 23.29% | +0.76 pct |
| 沪农商行 | 21.95% | 21.30% | +0.65 pct |
| 洪城环境 | 19.32% | 19.00% | +0.32 pct |
| 青岛港 | 21.12% | 20.90% | +0.22 pct |
| 格力电器 | 15.78% | 15.68% | +0.10 pct |
| 农业银行 | 23.62% | 23.62% | 0.00 pct |

本次筛选中排名与判定未发生翻转（受益于阈值 25% 留有余量），但**纯粹是运气**。若阈值设在 22%，唐山港会因 +0.99 pct 的虚增被错误剔除。对于阈值更紧、分红率更高的标的（银行股股息率 5%–6%，除权缺口 5%–6%），单次除权即可在 252 日窗口内显著抬高标准差。

### 3.3 隐蔽性风险

该缺陷最危险之处在于**静默**：视图正常返回、无 NULL、无异常、数据类型正确。任何新接入的分析人员都会默认 `qfq_close` 可用，从而在不知情的情况下得出偏差结论。本轮若未做除权日抽查，8 只组合的波动率数据会全部带着 0–1 pct 的污染直接交付。

## 四、根因推测（待维护方确认）

按现象判断，问题大概率出在复权因子环节，而非物化环节：

1. **`adj_factors` 为空或全为 1.0** —— 复权因子未从 `corporate_actions` 正确派生。复现时 `meta/revisions/data/adj_factors/` 下的分区文件存在但读取异常，需确认其内容是否为占位值。
2. **因子与行情未做 ASOF 对齐** —— 若按 `trade_date` 精确 join 而非 `ASOF JOIN`，除权日无对应因子时会回退为 1.0。
3. **前复权锚点选择错误** —— 前复权应以最新交易日为基准向前累乘因子，若锚点取在序列起点，结果等价于后复权甚至不复权。
4. **`adj_is_exact` 语义被忽略** —— 该字段为 false 时可能代表"因子缺失，退化为原始价"，但下游无任何强制校验。

建议优先排查第 1、3 两项。

## 五、期望行为

### 5.1 字段定义

| 字段 | 定义 | 约束 |
|---|---|---|
| `qfq_close` | 以**最新交易日**为基准，向前累乘复权因子得到的前复权收盘价 | 最新一日 `qfq_close == close`；除权日收益率不含分红缺口 |
| `hfq_close` | 以**序列首日**为基准的后复权收盘价 | 首日 `hfq_close == close`；除权日收益率不含分红缺口 |
| `adj_close` | 交易所口径的除权参考价调整 | — |
| `adj_is_exact` | 复权因子是否完整覆盖该日 | 为 false 时必须在文档/日志中显式告警 |

### 5.2 除权日收益率公式

前复权与后复权在除权日的收益率必须一致，且满足：

```
r_T = close_T / [ (close_{T-1} − 每股现金红利) / (1 + 每股送股 + 每股转增) ] − 1
```

即除权日收益率**不得**包含因分红送转造成的价格缺口。

### 5.3 验收标准

修复后需同时满足以下全部条件：

1. **恒等检验**：任意标的，最新交易日 `qfq_close = close`，误差 < 0.01 元。
2. **除权日检验**：随机抽取 50 个除权事件（覆盖现金分红、送股、转增、混合），除权日 `qfq` 收益率与该股当日实际市场涨跌（对照同期行业指数或同行）偏离 < 0.5 pct。
3. **连续性检验**：全市场 `|r_adj| > 7%` 且当日无 `corporate_actions` 记录的样本占比 < 0.1%（排除真实涨跌停/异动）。
4. **覆盖率检验**：`adj_is_exact = false` 的占比降至 < 5%（仅保留确实缺因子的退市/停牌标的）。基线值 60.9% 为 2026-10-15 单日快照（见 §2.3 口径边界），全量重算后的真实基线可能更高，以全量为准。
5. **回归检验**：以农业银行 2026-05-13 为例，`qfq_close` 在 05-12 与 05-13 之间应体现为小幅波动（≈ −0.15% 量级），而非 −1.77%。

## 六、临时绕过方案（当前已实施）

在修复上线前，所有依赖复权收益率的分析必须自行重建序列，**不得直接使用 `qfq_close`**。

实现方式（已封装，产物 `qfq_returns_rebuilt.parquet` 可复用）：

```python
# 1. 取原始收盘价
px = con.execute("""
    SELECT symbol, trade_date, close FROM daily_bars
    WHERE symbol IN (...) AND trade_date <= DATE '2026-10-15' AND close > 0
    ORDER BY symbol, trade_date
""").df()

# 2. 取除权事件（现金分红 / 送股比例 / 转增比例，单位：每股）
ca = con.execute("""
    SELECT symbol, CAST(ex_date AS DATE) ex_date,
           COALESCE(cash_dividend, 0)   cash,
           COALESCE(bonus_ratio, 0)     bonus,
           COALESCE(transfer_ratio, 0)  transfer
    FROM corporate_actions
    WHERE symbol IN (...) AND CAST(ex_date AS DATE) <= DATE '2026-10-15'
""").df()

# 3. 逐日计算：除权日修正分母，其余日直接计算
prev_adj = (close.shift(1) - cash) / (1 + bonus + transfer)
r = np.where(has_ex_date, close / prev_adj - 1, close / close.shift(1) - 1)
```

**关键点：**

- `bonus_ratio` / `transfer_ratio` 单位为**每股**送转股数（已用 688300.SH 2023-06-15 验证：送 0.49 股，68.01 → 45.83，理论参考价 45.64，吻合）。
- `corporate_actions.ex_date` 在部分 Parquet 分区中类型为 `BIGINT`，必须显式 `CAST(... AS DATE)`，否则报 `BinderException: Cannot compare BIGINT and DATE`。
- 若某日 `|r| > 7%` 且无对应除权记录，需人工确认是真实异动还是漏记除权，不可静默放过。

**该方案的成本**：每次分析都要额外写 40 行重建逻辑，且容易出现口径不一致（不同人用不同公式）。本轮已发现一处：早期版本按 `ex_date` 年份归集每股分红，导致高送转标的股息率被系统性低估（海尔智家 3.41%→3.88%、隆鑫通用 1.71%→3.56%）。**长期靠本地补丁不可持续。**

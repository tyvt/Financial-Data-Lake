## 一、问题

`daily_bars_adj.qfq_close` 与 `close` **数值完全相等**，前复权从未生效；`hfq_close` 同样如此。除权日的价格缺口被原样保留，`close / pre_close - 1` 把分红送转当成真实下跌计入收益率。

该缺陷**不抛异常、不返回 NULL、类型正确**，仅在 `adj_is_exact` 标记为 `false`，下游无任何强制校验可感知。

## 二、最小复现

```sql
SELECT trade_date, close, pre_close, qfq_close, hfq_close, adj_is_exact
FROM daily_bars_adj
WHERE symbol = '601288.SH'
  AND trade_date BETWEEN DATE '2026-05-11' AND DATE '2026-05-15'
ORDER BY trade_date;
```

实际输出（农业银行，2026-05-13 除权，10 派 1.30 元）：

| trade_date | close | pre_close | qfq_close | 表观涨跌 | adj_is_exact |
|---|---|---|---|---|---|
| 2026-05-12 | 6.78 | 6.79 | 6.78 | −0.15% | false |
| 2026-05-13 | 6.66 | 6.78 | 6.66 | **−1.77%** | false |
| 2026-05-14 | 6.65 | 6.66 | 6.65 | −0.15% | false |

每股派 0.13 元、除权前收 6.78 元，理论除权参考价 6.65，理论跌幅 1.918%；实测表观跌幅 −1.77%，与该分红率吻合，说明该日"下跌"全部来自除权，而复权序列未做任何调整。同类样本：601288.SH 2025-07-17 / 2025-12-15、601825.SH 2026-06-18，表现一致。

## 三、影响范围

| 计算类型 | 影响方向 | 量级 |
|---|---|---|
| 年化波动率 | 系统性高估 | 实测 0.0–1.0 pct |
| 区间涨跌幅（含分红再投资） | 系统性低估 | ≈ 累计分红率 |
| 最大回撤 | 系统性高估 | 视分红频率 |
| 夏普 / 信息比率 | 分子分母同时失真 | 不可预测 |
| 动量、均线、突破类指标 | 除权日假信号 / 假跌破 | 单日 −1%~−7% |

覆盖率现状（**口径：2026-10-15 单日截面快照，非全历史均值**）：`qfq_close = close` 行占比 ≈100%，`adj_is_exact = false` 占比 60.9%。因 revisions 分区读取被环境策略拦截，未做历史全量回溯；A 股除权高峰在 5–7 月，全量重算后的真实缺失率**可能高于** 60.9%，请勿以该值作为验收基线。

对本次筛选的实际影响：核心池 8 只中唐山港虚增 +0.99 pct（23.17% → 22.18%）、沪农商行 +0.65 pct、洪城环境 +0.32 pct。本次阈值 25% 留有余量，排名未翻转——**属于运气**。若阈值设在 22%，唐山港会被错误剔除。

## 四、验收标准（需全部满足）

1. **恒等**：任意标的，最新交易日 `qfq_close = close`，误差 < 0.01 元。
2. **除权日**：随机 50 个除权事件（现金分红 / 送股 / 转增 / 混合），除权日复权收益率与实际市场涨跌偏离 < 0.5 pct。
3. **连续性**：全市场 `|r_adj| > 7%` 且当日无 `corporate_actions` 记录的样本占比 < 0.1%。
4. **覆盖率**：`adj_is_exact = false` 降至 < 5%（仅保留确缺因子的退市/停牌标的），以全量重算结果为准。
5. **回归**：农业银行 2026-05-13 的 `qfq` 日收益应为 ≈ −0.15% 量级，不再是 −1.77%。

期望口径：`qfq_close` 以最新交易日为基准向前累乘因子；除权日收益率满足
`r_T = close_T / [(close_{T-1} − 每股现金红利) / (1 + 每股送股 + 每股转增)] − 1`。

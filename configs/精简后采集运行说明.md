# 选股数据湖自动更新

已改用明确白名单更新。自动任务只运行 `scripts/update_selection_lake.py`，不要再用无范围的 `cne init`、`cne run daily` 或 `--stale-only` 替代此入口；底层工具本身没有全局按数据集禁用开关。

## 计划

- Windows 任务：`CNEquity-SelectionLake-Update`。
- 北京时间每天 **19:30** 更新、**22:30** 补跑失败阶段。已成功阶段当天跳过。
- 有前一日程序失败的计划时优先恢复，并沿用原交易日；跨日或周末不会把尚未发布的数据误判为无需更新。覆盖不足的告警会保留在状态中，不伪装成完整成功。
- 股票行情/财务遵守交易日门禁；公告、监管与新闻按自然日更新。
- 以SYSTEM运行，不需要保持登录；错过时间会在系统可用时补跑。需要电脑开机、网络可用，以及现有本机代理服务正常运行。
- 最长90分钟；任务禁止重叠。已有其他项目的任务保持原样。
- 更新完成后清理多余版本副本：保留每表最近两版、当前版、登记引用/保护版本；逐文件校验并写入删除日志。存在程序失败、未完成删除或内容异常时保留数据并报出状态。银行及治理事实历史不按行情版本规则删除。

## 更新范围

- 行情、分红送转配股、证券资料、交易状态、交易日历、必要财务、历史股本。
- 东财和申万行业分类：前者用于沪市豁免，后者用于组合集中度。
- 财报披露日、公告、监管事件、新闻，以及派生复权因子。
- 银行专项：核心一级资本、不良率、拨备覆盖；带报告期及抓取时间。
- 实控人原始披露、治理核查当前结果和历史规则快照。

`configs/selection_lake_policy.json` 是白名单。调度启动时检查配置和传递依赖；运行中阻止非白名单步骤抓取、阻止被排除数据集发布。

已经清空的B组数据、期货、期权、指数及成分、十大股东、机构持仓、股东户数、限售解禁、行业指数等均不进入定时更新。原数据退役后保留零行结构和版本凭证，避免旧查询因表消失报错。

## 外部接口及失败处理

- 当前持仓实控人、持仓/观察池银行优先每天检查；其他已筛选实控人和全市场银行按7天周期轮转。
- 单次最多请求16家银行、20只股票实控人；请求间隔1.2秒，连续3次失败停止本轮同源访问。首次补齐会跨若干次任务完成，不冒充已全市场实时刷新。
- 请求失败保留已有数据，记录错误，不将缺失改成0或无实控人。
- 银行原始事实位于 `derived/bank_risk_metrics`；实控人原始事实位于 `derived/actual_controller_disclosures`；治理历史位于 `derived/governance_history`，当前判断仍兼容 `derived/ownership_check` 和CSV。
- 事实发生变化时保留新快照；完全相同事实去重。接口未提供原始披露时间的记录保留空值，不用抓取时间冒充公告时间。
- 治理快照带规则及白名单的哈希。首次导入旧缓存不冒充旧时点的完整原始披露历史。
- 复核银行指标优先读湖内；缺失时现场取数并入湖。规则阈值与股票权重没有自动修改，任务不下单、不自动买卖、不重写最终组合。
- 保持现有Windows本机代理的同一地址，修正HTTPS CONNECT的代理协议配置；没有切换出口或关闭TLS校验。

## 每周公开源抽检

另一个任务 **`CNEquity-SelectionLake-Audit`**：北京时间每周六 09:00 运行，约 2–4 分钟。**只读**：只比对行情、分红、财务、证券资料和行业分类，并向腾讯/新浪/东财发起公开请求，不修改湖内任何数据。

- 明细：`分析产出/数据湖抽检_公开源比对明细.csv`；汇总：`分析产出/数据湖抽检_公开源比对.json`。
- 历史与漂移：`logs/selection_update/public_audit_history.jsonl`。**只有新增的未解释差异才会把运行状态标为 warning**；已知且已记录的差异不会反复报警。
- 安装：`powershell -ExecutionPolicy Bypass -File scripts/install_audit_task.ps1`。
- 手动运行：`python scripts/audit_lake_public.py`（工作目录取仓库根，脚本内部按绝对路径解析）。
- 该任务的退出码非 0 只说明抽检发现问题或失败，不影响数据更新任务。

## 数据不足不出数

`分析产出/data_sufficiency.py` 供沪深筛选共用：样本不足时返回"数据不足"，而不是给出一个带缺陷的数值。

- 复权收益：观测数 ≥200 **且**窗口内行情天数 ≥252，否则不参与波动/回撤/12个月收益判定。理由是 ffill 能把长期停牌凑成 200 个非空值，但那不是价格波动，是常数。
- 流动性：近 63 个交易日至少 60 日有成交，否则 ⑬ 不成立。
- 财务科目：任一年缺失即整项不成立，不用其余年份冒充三年（与脚本既有 skipna=False 一致）。
- 每只被排除的标的都会带上原因列（`vol_reason`），漏斗表可查，不会静默消失。

## 查看状态与手动执行

```powershell
Get-ScheduledTask -TaskName CNEquity-SelectionLake-Update
Get-ScheduledTaskInfo -TaskName CNEquity-SelectionLake-Update
Start-ScheduledTask -TaskName CNEquity-SelectionLake-Update
```

只检查白名单，不发请求：

```bash
python scripts/update_selection_lake.py --check
```

只更新外部银行及实控人：

```bash
python scripts/update_selection_lake.py --external-only
```

日志与结果：

- `logs/selection_update/last_run.json`：最近一次执行、实际处理日期及阶段结果。`warning`表示仍有覆盖缺口或接口异常，需查看各阶段详情；已验证数据仍可正常入湖。
- `logs/selection_update/update.log`：详细滚动日志（单文件5MiB，最多保留5份历史）。
- `logs/selection_update/external_status.json`：各股票接口最近成功检查时间。
- `logs/selection_update/task_registration.json`：Windows任务注册和下次运行时间。

暂停：`Disable-ScheduledTask -TaskName CNEquity-SelectionLake-Update`。重新安装：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install_selection_task.ps1`。
